# Celebration Suite v1.2.6 — Premium Workspace Header

This focused release redesigns the planner workspace header after visual QA exposed cramped controls on wide desktop layouts.

## Changes
- Replaced the Guided/Professional dropdown with a persistent two-state segmented control.
- Kept the existing functional experience-mode behavior and event-workspace rerendering.
- Rebuilt Search as a stable command button with Cmd/Ctrl+K hint.
- Prevented Search text/icon wrapping and vertical collapse.
- Grouped workspace controls into a deliberate premium action cluster.
- Refined Event Workspace brand alignment and Dashboard action.
- Added responsive behavior for tablet and mobile.
- Bumped service-worker cache to celebration-suite-v126.

No database migration is required.
