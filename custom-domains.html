How setup works

  1. Add the domain here.
  2. Create the TXT verification record shown below.
  3. Point the domain to Celebration Suite using your DNS provider.
  4. Click Verify & Activate. If Netlify API credentials are configured, the alias is provisioned automatically.
For safest setup, use a subdomain such as portal.example.com rather than replacing your main marketing website.
