# v0.2 - CRM, Proposals, Contracts, and Financials

This release adds the professional planner business layer while preserving the v0.1 multi-tenant licensing and white-label architecture.

## Added
- Tenant-scoped lead CRM with seven stages and drag/drop movement
- Follow-up dates, priorities, source, event details, budget, and activity history
- Email lead action using the planner's own connected email provider
- Lead conversion into a client and event
- Single Event license cap is enforced during conversion
- Tenant client records
- Branded proposals with totals, deposits, scope, terms, validity date, public tokenized review link, and client acceptance
- Branded contracts with public tokenized e-sign acknowledgment, signer name/email, timestamp, and request IP capture
- Financial Center with invoice creation, manual payment recording, billed/collected/outstanding/overdue summaries
- Optional tenant-owned Stripe secret key, encrypted at rest
- Stripe Checkout invoice links that pay the planner directly
- Server-side Stripe return verification and idempotent payment recording

## Security / isolation
Every professional-business table contains tenant_id and every private API scopes requests to the authenticated tenant. Public proposal and contract pages can only load a single document through its unguessable public token.

## Important legal note
The included contract signature flow is a basic electronic acknowledgment mechanism. Sellers should obtain legal review for their own terms, disclosures, retention requirements, and electronic-signature compliance before marketing it as a legally sufficient e-signature solution in every jurisdiction.
