# Celebration Suite v0.6.2 OAuth Redirect Hotfix

## Fix
Google OAuth start, token exchange, and post-login redirects now derive the public origin from the actual incoming request URL instead of `SITE_URL`.

This prevents Celebration Suite logins on `planner.sageandcelebration.com` from being redirected to the Sage & Celebration root site when a stale or inherited Netlify environment value exists.

## Security
- OAuth state signing remains unchanged.
- Role/email gating remains unchanged.
- Session cookies remain host-only.
- `SITE_URL` is still used elsewhere by the application, but no longer controls Google OAuth callback origin.
