# Celebration Suite v0.24.3 — Dashboard Navigation Cleanup

The planner dashboard now has one navigation system only.

- Removed the duplicated slim icon dock from the dashboard.
- Removed the large “What are you working on today?” task launcher.
- Removed the floating “Do something” launcher globally.
- Simplified top actions to New Event, Settings, and Sign Out.
- Reduced dashboard navigation to the primary planner modules.
- Event-specific planning remains inside Event Workspace after opening an event.
- Dashboard now focuses on finding, creating, and opening events.
