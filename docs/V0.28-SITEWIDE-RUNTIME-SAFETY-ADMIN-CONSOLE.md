# Celebration Suite v0.28.0 — Sitewide Runtime Safety + Platform Admin Console

## Runtime hardening
- Added `/assets/runtime-compat.js` across every HTML application page.
- Legacy Sage pages that refer to element IDs as global variables now receive a safe compatibility binding before page initialization.
- Browser-reserved globals are never overwritten.
- Added automated `tools/audit-runtime-globals.mjs` preflight to fail releases with unsafe ID collisions.
- Normalized Event Day event IDs so `id`, `event_id`, and `booking_id` are accepted.
- Event Day guest check-in preserves the current event context.
- Explicitly repaired real `status`, `history`, and `event` browser-global collisions found by the audit.

## Platform owner console
`/platform-admin.html` now provides owner/support views for:
- Tenants and account drill-down
- Users, roles, status and last login
- Support tickets and resolution updates
- Audit/activity history
- Integrations and last errors
- License status and renewal/expiration
- Centralized error logs when an error-log table exists
- Existing license/order fulfillment data

`/.netlify/functions/platform-observability` authenticates through the existing platform-admin session and reads tenant-safe diagnostics with the Supabase service role. It also enriches tenant users with Supabase Auth `last_sign_in_at` when available.

## Support workflow
A support case can be opened in Platform Admin, tied back to the tenant, and investigated against that tenant's users, last login, events, audit history, integrations and license state without entering the customer's planner blindly.
