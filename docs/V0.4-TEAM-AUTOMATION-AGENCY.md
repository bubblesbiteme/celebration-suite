# v0.4 — Team, Agency Operations & Automation

This release adds agency/team operations to the standalone white-label event planning platform.

## Team accounts and permissions
- Owner, Admin, Planner and Staff roles.
- Seven-day tokenized team invitations.
- Individual staff passwords using the same secure session system as planner accounts.
- Per-user permission overrides for events, CRM, proposals, financials, vendors, inventory, guests, approvals, floor plans, Event Day and time tracking.
- Disabled team accounts lose session access on their next request because the server revalidates the tenant user record.

## Event assignments
Planner and staff accounts are assigned to specific events. Core event/event-day/guest/registration/floor-plan/approval APIs enforce assignments server-side. Owners and admins retain tenant-wide event access.

## Labor and time tracking
- Clock in/out.
- Optional event assignment on each time entry.
- Hourly labor rate stored on the team profile.
- Hours and estimated labor cost roll up automatically.
- Owners/admins can review all team time while normal team members see their own entries.

## Automation Center
Five automation types are included:
1. Stale lead reminders.
2. Overdue invoice reminders to clients.
3. Event countdown reminders at configurable day intervals.
4. Client checklist reminders when a checklist item has a recognizable YYYY-MM-DD due date.
5. Automatic post-event closeout.

The automation runner is scheduled hourly by Netlify. Dedupe keys prevent repeat sends for the same rule/entity/cycle.

All outgoing automation email uses the tenant's own configured Resend or SMTP connection.

## Automatic event closeout
After the configured number of days following an active event:
- the event is marked completed;
- a closeout record is created;
- guest/registration/vendor summary counts are captured;
- the owner receives a completion email when email is configured;
- the event can be reopened from Event Closeouts.
