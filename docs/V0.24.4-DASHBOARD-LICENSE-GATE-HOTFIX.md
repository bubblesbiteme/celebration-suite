# Celebration Suite v0.24.4 - Dashboard License Gate Hotfix

Fixes a regression introduced during the dashboard navigation cleanup where removed dashboard statistic cards were still referenced by JavaScript. That runtime error was caught by the generic dashboard bootstrap handler and incorrectly redirected valid users to the Access Paused / license-expired page.

Changes:
- Removes stale dashboard statistic element references.
- Dashboard only redirects to license-expired on an actual HTTP 402 license response.
- HTTP 401 redirects to sign-in.
- Other bootstrap failures remain on the dashboard with a retry message and do not alter or misrepresent license state.
- Shared API errors preserve HTTP status codes.
- Tenant license selection prefers a currently usable license when multiple active/grace/past-due rows exist.

No database migration required.
