# Celebration Suite v0.29.0 — Knowledge Base & Getting Started

This release adds an in-app user education system.

## New pages
- `/getting-started.html` — guided first-time setup path.
- `/knowledge-base.html` — searchable, categorized step-by-step help center.

## Knowledge areas
Getting Started, Events, Design, Inventory, Guests & RSVP, Money, Vendors, Communications, Integrations, Team, Documents, Client Portal, Event Day, Setup & Branding, Troubleshooting, and Platform Administration.

## Contextual help
`assets/app.js` now maps major application routes to the most relevant Knowledge Base article and adds a `? Help` action to the page header. Pages without a compatible header receive a small fallback Help action.

## Support workflow
The Support Center now sends users to the Knowledge Base / Getting Started guides before ticket submission while keeping ticket creation available.

## Settings
White-Label Settings now includes a Help & Learning section linking to Getting Started, Knowledge Base, and Support.

## No database migration
The Knowledge Base is shipped as static application content and requires no database migration.
