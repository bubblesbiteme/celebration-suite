# Celebration Suite v0.22.0 — Floor Plan Pro Library & UX

This release replaces the repetitive floor-plan onboarding and small demo-style palette with a professional event-layout library.

## Highlights
- One quick-action strip instead of duplicated Start Here blocks
- 100+ professional event objects across seating, ceremony, decor/floral, production, food/beverage, guest experience, logistics, custom shapes/notes and outdoor/specialty
- Searchable category tabs
- Favorites and recently used objects
- Master Inventory integrated into the same library with item images and quantities
- Starter layouts for receptions, ceremonies, cocktail events, galas and corporate events
- Snap-to-grid and grid visibility controls
- Exact canvas dimensions and real-world dimensions
- Seats, rotation, layering, assignments and setup notes
- Keyboard nudging/delete controls
- Improved object counts and seat-capacity stats
- Existing saved floor plans remain compatible

No database migration is required.
