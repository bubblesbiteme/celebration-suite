# Celebration Suite v0.19.0 — Full UI/UX Overhaul

This release is a product-wide interface redesign focused on discoverability, visual hierarchy, reduced empty space, and task-first navigation.

## Global planner shell
- Persistent icon navigation rail on desktop and bottom navigation on mobile.
- Home, Event, Design, Floor Plan, Guests, Inventory, Money, Inbox and Settings are always one click away.
- Current area is visibly highlighted.
- Event-aware links preserve the active event where appropriate.

## Visual system
- Softer cards and borders, warmer layered background, improved typography and spacing.
- Consistent 1380px maximum working width to eliminate full-screen blank areas.
- Strong primary action styling and reduced pill-button clutter.
- Improved forms, tables, tabs, badges and empty states.
- Responsive mobile behavior.

## Task-first guidance
High-use pages now open with a Start Here panel using plain-language actions.

Inventory:
- Add one item
- Bulk upload
- Scan QR
- Print labels

Event Inventory:
- Choose items
- Pack
- Check out
- Return

Financials:
- Create invoice
- Record payment
- See overdue

Guests:
- Add guests
- Import list
- RSVP QR
- Check in

Floor Plan:
- Round table
- Long table
- Chair
- Venue plan

Design Studio:
- Add picture
- Use inventory
- Get approval

## Empty states
Empty screens explain what belongs there and the next action rather than displaying a large blank box.

## High-use page density
- Inventory uses a responsive card grid instead of a narrow list floating in blank space.
- Event Inventory is constrained to a readable work area and keeps picker + packing workflow visually connected.
- Financials uses a compact working width and clearer hierarchy.
- Event Workspace is constrained and visually grouped.

## Technical
- New global `/assets/ui-v019.js` planner UI enhancement layer.
- Public/client-facing pages are excluded from the planner navigation shell.
- No database migration required.
