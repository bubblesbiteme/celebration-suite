# Celebration Suite v0.12.0 — Platform Control & Intelligence

Adds SaaS-grade control, accountability and integration capabilities:

- Notification Center with unread/read workflow.
- Tenant audit/client activity history.
- API & Webhook Integration Center.
- Secure one-time API key issuance with hashed storage.
- External API endpoints for events and leads, including lead intake.
- Signed outbound webhooks with delivery logging.
- Client portal activity generates audit records, planner notifications and `client.activity` webhooks.
- Expanded Owner BI dashboard with monthly revenue, event profitability, labor/vendor/referral costs and inventory utilization.
- Backup/export coverage for new audit, notification and integration data.
