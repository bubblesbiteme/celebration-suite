# Celebration Suite v0.26.1 - Inspiration Inventory Picker Hotfix

Restores the original Sage & Celebration Inspiration Board inventory selection flow.

- Event Workspace button now opens `/inventory-design-picker.html?booking_id=<event>`.
- Picker loads tenant-scoped Master Inventory with item photos, SKU/category, owned quantity and storage location.
- Planner chooses a requested quantity and adds the inventory item to the event Inspiration Board.
- Adding to the board does not reserve inventory until the design is approved.
- Existing inventory-backed design items are detected to avoid duplicate board entries.
- After selection the planner is returned to the same Event Workspace Design tab and the created/existing design item is identified in the URL.
- No database migration required.
