# Celebration Suite v0.8 — Operations Expansion

## Added
- Communications Center with tenant email, Telnyx SMS, and internal notes.
- Telnyx SMS integration fields in Brand & Integrations.
- Referral partner and commission tracking with earned/paid status.
- Change orders with public client approval/decline links.
- Document Vault for business-wide or event-linked file URLs and visibility.
- Business Intelligence dashboard covering billed/collected/outstanding revenue, vendor spend, commissions, inventory value, lead conversion, event mix, and lead sources.
- Inventory metadata for item images, storage location, condition, rental eligibility, rental price, barcode/QR lookup code, and reservation check-out/check-in fields.
- Expanded account export to include new operational tables and correct inventory table names.

## Database
Run migration `0009_OPERATIONS_EXPANSION.sql` after the previous migrations.

## Integrations
SMS sending requires a tenant Telnyx API key and sending number configured in Brand & Integrations.
