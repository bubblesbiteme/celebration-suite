# Celebration Suite v0.31.0 — Original Client Portal Parity & Access

This release completes the direct-fork client portal pass against the original Sage & Celebration client portal and makes planner/client collaboration use the same tenant-scoped event records.

## Original portal parity

The Celebration Suite client portal now preserves the original Sage client portal navigation and interaction model for:

- Overview and Action Center
- Checklist and Timeline
- Appointments
- Inspiration Board
- Floor Plan
- Documents
- Messages
- Questionnaires
- Approvals and Change Orders
- Payments and Budget
- Invitations and Guests
- Client profile and notification settings

All 27 client actions used by the original portal are represented by the tenant-safe compatibility backend.

## Shared planner/client records

Planner and client surfaces use the same event records rather than separate portal copies:

- `tenant_messages`
- `tenant_documents`
- `tenant_inspiration_items`
- `tenant_inspiration_boards`
- `tenant_floorplans`
- `tenant_questionnaires`
- `tenant_approvals`
- `tenant_change_orders`
- `tenant_guests`
- `tenant_appointments`
- `tenant_invoices`
- `tenant_payments`

Internal planner notes remain planner-only. Client-visible planner messages and client replies use the shared event conversation.

## Two-way collaboration

- Inspiration Board approvals, feedback, arrangement, size, rotation and layer changes write to the same inspiration records the planner uses.
- Shared-editable Floor Plans persist named layouts, objects, room dimensions, background settings, measurements and client edits to the same floor-plan records used by the planner.
- Client document uploads enter the same event document vault and retain client attribution.
- Questionnaires, approvals, change orders, guests, appointments and payment records stay synchronized through the same tenant data.
- Planner and client surfaces refresh shared state on focus and on a periodic interval.

## Client access

Each event provides an event-specific first-time invitation URL. The planner can copy or email this link from Client Access.

Each tenant also has a permanent returning-client login URL:

`/client-login.html?tenant=<tenant-slug>`

This URL can be placed on the planner's website as a permanent Client Login button. The planner interface can copy both the URL and ready-to-paste HTML:

`<a href="<tenant-login-url>" target="_blank" rel="noopener">Client Login</a>`

After authentication, returning clients land on My Events and only see events granted through `tenant_client_event_access`.

## Preview behavior

Planner Preview Client Portal uses planner authorization to render a read-only view of the same client portal. It does not require the planner to log in as the client and does not permit preview actions to modify client data.

## Password reset

Event-specific client sign-in provides a Forgot Password link tied to the secure event invitation token. The permanent tenant login explains how to recover access when no event invitation token is present.
