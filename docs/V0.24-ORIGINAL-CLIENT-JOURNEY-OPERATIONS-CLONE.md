# Celebration Suite v0.24.0 — Original Client Journey & Operations Clone

This release continues the behavioral clone strategy introduced in v0.23. The uploaded Sage & Celebration Phase 9 build is the source of truth for planner workflow behavior; multi-tenant isolation, white-label branding, and license controls remain Celebration Suite-specific.

## Rebuilt workflows

### Event Workspace
- Original-style primary planning tabs plus grouped More Tools
- Checklist with task status, priority, owner, due date, edit/delete
- Timeline list + calendar views and event ICS export
- Proposed / approved / actual working budget
- Internal notes and event messages
- Client portal permissions and preview
- Direct access to design, floor plan, guests, questionnaires, inventory, vendors, staff, labor, ticketing, QR check-in, financials, activity history and closeout
- 2.5-second autosave, local recovery, hidden-page save and explicit secure save state

### Guest Management / RSVP
- Event-level invitation settings and preview
- Full guest operational fields: party size, attending count, children, plus one, meal, dietary, accessibility, table, seat, hotel, transportation, tags, VIP, check-in notes
- CSV import and multiple exports
- Bulk RSVP/table/VIP/check-in operations
- Personalized RSVP links
- Per-guest QR payloads
- Send unsent invitations
- Ticket holders displayed alongside RSVP guests

### Financial Center
- Event selector and complete event ledger
- Service Fee / Labor + Decor Allowance contract split
- Invoices, Stripe payment-link creation, recorded payments
- Business vs client-funded decor expenses
- Discounts, credits, refunds, fees and tax adjustments
- Service-profit / decor-remaining summaries

### Questionnaires
- Reusable template library
- Full template create/edit/delete
- CSV template import
- Assign template or custom questionnaire to event
- Review submitted answers
- Analyze missing planning details
- Create planning tasks from questionnaire analysis
- Client links and printable QR codes

### Client Portal
- Original-style DO THIS NEXT prioritization
- Questionnaire → approval/change order → planning task → invoice priority
- Shared checklist task completion
- Design approvals and client notes
- Guest list editing and invitation sending
- Shared floor-plan object editing where planner permits
- Vendor options, appointments, documents and financials
- 45-second refresh plus focus/visibility reconnect
- Local + cloud message draft recovery and 2.5-second secure autosave
