# Celebration Suite v0.23.0 — Original Workflow Core Clone

This release resets the implementation strategy for core planner workflows. The uploaded Sage & Celebration phase-9 application is the behavioral source of truth.

## Inventory
- Inline Add/Edit inventory form restored.
- Saving creates the inventory record first, with persistent QR identity and generated internal SKU when blank.
- QR label is generated from the saved record; scanning a printed label opens the phone lookup page.
- Item lookup shows photo, item name, exact storage location, SKU, category, quantity, condition, status and notes.
- Floor-plan symbol, multiplier and auto-reserve fields restored.
- Date availability view restored.
- CSV import includes original operational fields.
- Bulk photo matching remains available.
- Inventory-admin compatibility route uses the same implementation.

## Floor Plan
- Rebuilt around the original floor-plan interaction model.
- Original professional object catalog and category accordions.
- Drag library item onto canvas using native floor-type payload.
- Tap/click library item to add as fallback.
- Drag placed item using pointer movement.
- Multiple layouts: new, duplicate, rename and delete.
- Save + share and version snapshots.
- Room dimensions and snap-to-grid.
- Rotate, duplicate, delete and clear selected objects/layout.
- Venue plan background upload, opacity and removal.
- Distance measurement.
- Guest/vendor assignment and setup notes.
- Print/PDF.
- Floor-plan save synchronizes mapped inventory reservations.
