# Celebration Suite v0.6 — Monthly Billing + Unified Authentication

## Monthly Unlimited
- Public price: $59/month.
- Unlimited events.
- Stripe Checkout uses recurring subscription mode.
- Stripe webhooks synchronize successful renewals, failed payments, subscription updates and cancellations.
- Failed payment starts an internal billing-recovery window in the database.
- The recovery duration is not displayed on public pricing, billing, account, legal marketing copy, or client portal pages.
- Once the internal recovery window ends without payment, planner/team access is blocked and automations stop because active-license checks fail.
- Client portals show a neutral temporary-unavailability message.
- Billing recovery uses Stripe Billing Portal for payment-method updates.

## Unified sign-in
### Platform administration
- Email/password login.
- Google login for approved platform-admin email addresses.
- `PLATFORM_OWNER_EMAIL` may bootstrap the first platform owner through verified Google identity.
- `PLATFORM_ADMIN_KEY` remains an emergency/first-time bootstrap credential and is no longer the normal daily login.

### Planner/team accounts
- Email/password.
- Google sign-in when Google email matches an existing active tenant user.
- Team invite can be accepted with password or the exact invited Google email.

### Client accounts
- Portal invite token identifies the tenant/event but no longer grants workspace access by itself.
- Client creates an email/password account or uses the Google account matching the event invitation email.
- Client account must have explicit event access before portal data is returned.

## New environment values
- `STRIPE_PRICE_MONTHLY`
- `PUBLIC_PRICE_MONTHLY=59`
- `GOOGLE_OAUTH_CLIENT_ID`
- `GOOGLE_OAUTH_CLIENT_SECRET`
- `GOOGLE_OAUTH_STATE_SECRET` (recommended; falls back to `SESSION_SECRET`)

## Google callback
Add this authorized redirect URI to the Google OAuth web application:

`https://planner.sageandcelebration.com/.netlify/functions/google-auth-callback`

## Stripe webhook
Create a Stripe webhook endpoint at:

`https://planner.sageandcelebration.com/.netlify/functions/stripe-webhook`

Subscribe at minimum to:
- `invoice.paid`
- `invoice.payment_failed`
- `customer.subscription.updated`
- `customer.subscription.deleted`

Copy the endpoint signing secret into `STRIPE_WEBHOOK_SECRET`.
