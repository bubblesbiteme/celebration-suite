# v0.21 Deep Operations & Workspace Parity

This release ports another operational slice from the original Sage & Celebration planner.

## Vendor operations
- per-event vendor arrival roster
- arrival/load-in times
- assigned event area
- responsibilities, access instructions and day-of notes
- vendor check-in/check-out/reset
- emergency contacts
- compliance status from vendor-linked dated documents

## Event day
- vendor arrivals are visible and actionable in the command center
- emergency contacts are visible without leaving event day
- same vendor status updates are shared with Vendor Operations

## Event book / BEO
Adds a fourth packet: BEO / Function Sheet, including guest count, room setup, food/dietary questionnaire notes, vendor arrivals and staffing.

## Timeline
- list/calendar toggle
- month navigation
- timeline item ICS export
- event calendar ICS export

## Offline/installable shell
- web app manifest
- service worker
- offline fallback page
- cached event-day/QR/inventory scan shells
