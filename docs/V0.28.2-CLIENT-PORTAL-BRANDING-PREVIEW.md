# v0.28.2 Client Portal Branding & Preview Recovery

This release repairs white-label branding and planner preview behavior.

## Branding
- Tenant business name is shown on the client portal.
- Tenant logo_url is used when configured.
- If no tenant logo is configured, a neutral initials badge is shown.
- Celebration Suite / Sage artwork is never used as a tenant-logo fallback.
- Tenant primary, secondary and accent colors are applied as CSS variables.
- The Event Workspace uses the same tenant-branding helper.

## Client Portal preview
- Planner preview uses `?preview=1` and authenticates with the planner tenant session.
- Preview is read-only.
- Real client portal access still requires the client session and event access record.
- Preview and live-client modes share the same portal renderer and event data source.

## Route consistency
- `event.html` and `event-workspace.html` are synchronized to prevent UI/behavior drift.
