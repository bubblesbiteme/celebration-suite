# v0.3 Advanced Planning Tools

Added to the standalone white-label platform:

- Vendor CRM with event assignments, quote/contract/paid tracking, status, and notes.
- Master inventory with quantities, replacement values, per-event reservations, and same-date conflict enforcement.
- Advanced guest list with RSVP status, party size, meals, dietary notes, seating, and check-in.
- Public white-label RSVP link per event.
- Appointments for consultations, walkthroughs, tastings, rehearsals, and meetings.
- Client approvals with secure tokenized public decision links.
- Registration and ticket types with capacity, free/paid pricing, public registration, tenant-owned Stripe checkout, verification, and check-in.
- Drag-and-drop floor plans stored as structured JSON per event.
- Event Day command center combining guest check-in, registration check-in, appointments, vendors, inventory, and pending approvals.

Security / tenancy:

- Private APIs require an active license and derive tenant identity from the signed session.
- All private CRUD queries are scoped to the authenticated tenant.
- Public RSVP, approval, and registration surfaces expose only token-addressed resources.
- Paid registrations use the planner tenant's encrypted Stripe integration, not the platform owner's payment account.
- The Single Event license cap continues to be enforced by the event creation API.
