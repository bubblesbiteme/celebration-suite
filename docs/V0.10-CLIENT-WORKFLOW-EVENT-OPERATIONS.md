# Celebration Suite v0.10 — Client Workflow & Event Operations

This release closes several workflow gaps between the original Sage & Celebration planning portal and Celebration Suite.

## Added
- Reusable questionnaire templates and event questionnaire assignments.
- Public branded questionnaire completion with required-field validation and submission review.
- Rich client portal tabs for planning, questionnaires, approvals, change orders, financials, shared documents and messages.
- Event inventory reservation, packing, checkout and return workflow.
- Printable event packing list and return status view.
- Printable Final Event Book combining event details, checklist, timeline, vendors, guests, inventory, questionnaires, approvals, documents and financial summary.
- Support ticket center for tenant issue tracking.
- Full account Backup & Export screen.
- Export coverage for questionnaires, support tickets, calendar blocks and inspiration boards.
- Vendor-linked document vault records.
