# Celebration Suite v0.24.5 - Event Workspace Recovery

- Replaced browser ID-global assumptions in Event Workspace with explicit DOM bindings.
- Supports both `?id=` and `?event_id=` event URLs.
- Dynamic task/timeline/budget/note/message controls now bind explicitly.
- Generic workspace load failures no longer redirect to login or leave a blank shell; the page shows a retryable error state.
- No database migration required.
