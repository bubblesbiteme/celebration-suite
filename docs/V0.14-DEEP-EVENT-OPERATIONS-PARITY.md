# Celebration Suite v0.14 — Deep Event Operations Parity

This release continues the parity-first rebuild against the original Sage & Celebration planner portal.

## Guest & Invitation Suite
- Event-specific invitation title, message, time, location, RSVP deadline and visual style.
- Meal choices, plus-one, dietary and song-request options.
- Personalized invitation codes and RSVP URLs.
- Invitation send-one / send-all using each tenant's connected email provider.
- Invitation sent/opened and RSVP-submitted timestamps.
- Guest household, VIP, tags, seating, meal, dietary and attendance state.
- CSV guest template, bulk CSV import and export.
- Bulk RSVP actions.
- Dedicated mobile check-in screen.
- Client portal guest editing, personalized invitation sending and RSVP link copy.

## Professional Floor Plan Studio
- Categorized drag/drop library covering seating, ceremony, production, F&B, guest experience and logistics.
- Custom rectangles, circles, zones, lines and labels.
- Exact width/height, rotation, seats, assignment and real-world feet dimensions.
- Master Inventory-backed floor plan objects.
- Venue-plan background upload and opacity control.
- Room dimensions and saved measurements.
- Client-share flag.
- Named floor-plan versions and immutable version snapshots.
- Client portal read-only display of shared layouts.

## Document & Agreement Vault
- Direct file upload up to 30 MB to private Supabase Storage.
- Short-lived signed URLs generated when private files are opened.
- Event and vendor association.
- Client-visible/internal visibility.
- Version chains.
- Locked permanent records.
- Issue and expiration dates with expiring/expired indicators.
- Contract, COI, W-9, license/permit and deposit-receipt workflows.

## Closeout & Archive
- Scheduled daily past-event closeout creation.
- Past event archive behavior without deleting event history.
- P&L snapshot covering billed, paid, outstanding, vendor cost and labor cost.
- Inventory-return verification gate.
- Vendor-review completion gate.
- Review-request and portfolio-permission tracking.
- Finalize & Archive workflow.
- Reopen support.

## Dashboard / Workspace
- Active / All / Archive event filters.
- Past events automatically display as archived.
- Event workspace permissions now include Invitations & Guests and Shared Floor Plan.
- Event workspace includes direct Closeout & Archive access.
