# Celebration Suite v0.13.0 — Deep Workspace & Design Studio

This release changes the parity strategy from adding isolated pages to porting the deeper workflows of the original Sage & Celebration planning portal.

## Design Studio
- Replaces the lightweight Inspiration Board with a persistent freeform collage canvas.
- Drag, overlap, resize in two dimensions, rotate, layer forward/back, lock positions, zoom and auto-arrange.
- Double-click image lightbox.
- Planner-defined categories and idea / shortlisted / approved / rejected states.
- Client visibility per design item and client feedback notes.
- Shared planner/client canvas positions when client arrangement is enabled.
- Master Inventory gallery with search, categories, photos, owned quantities and storage context.
- Inventory-linked design quantities reconcile into event reservations when designs are approved or rejected.
- Image uploads to a tenant/event-scoped Supabase Storage path (6 MB image limit).
- Board title, background, canvas height, notes and client-arrangement permission persist per event.

## Event Workspace
- Rebuilt around an event command-center experience rather than a collection of thin links.
- Overview with progress, open work, budget and date KPIs.
- Integrated module launcher for design, floor plan, guests, questionnaires, inventory, purchasing, approvals, documents, event day, event book, labor and activity.
- Four-state planning checklist with owner, due date, priority, overdue treatment and autosave.
- Rich timeline/run-of-show entries with date/time, owner/vendor, status and notes.
- Multi-column event budget with category, vendor, proposed, approved, actual, paid and client-visible state.
- Event-specific communications view and direct client email.
- Per-event client portal permissions, including design-board arrangement permission.
- Event details, duplication, rescheduling and cancellation controls.

## Client Portal
- Adds a real Design Board tab using the same stored board as the planner.
- Client can shortlist, approve, reject and comment on visible design items.
- Client can rearrange unlocked board items when enabled by the planner.
- Client design changes create audit records, planner notifications and webhooks.
- Fixes client activity session handling discovered during the parity review.

## Event Book
- Adds design-board images, status and inventory quantities to the final event book.
- Updated timeline rendering understands the richer workspace model.
