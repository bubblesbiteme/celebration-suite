# v0.22.3 — Floor Plan Interaction + Modern UX

This hotfix repairs the floor-plan interaction layer and modernizes its workspace UI.

## Interaction repairs
- Existing canvas objects move with live pointer dragging without DOM replacement during the gesture.
- Library cards use native drag data and can be dropped at the cursor location on the canvas.
- Built-in catalog items and Master Inventory items are both draggable.
- Click-to-place remains supported for touchpads, keyboard users, and browsers where drag is inconvenient.

## UX changes
- Modern search field with correctly aligned search icon and clear action.
- Styled event, layout, and starter-layout selectors.
- Reduced duplicated controls: the quick strip is shown only in simplified mode.
- Clear Simplify / Full Tools toggle with persistent state and visible mode feedback.
- Simplified mode hides advanced floor-plan controls and specialty categories and adds a four-step guide.
- Full Tools shows the complete professional catalog, versions, grid/snap, measurements, and room settings.
