# Celebration Suite v0.16.0 — Easy Mode + Floor Plan Visibility

This release makes usability a product-level feature rather than a per-page polish pass.

## Easy Mode
- Enabled by default and remembered per browser.
- Simplifies the dashboard navigation to core workspace choices.
- A persistent **Do something** launcher is available across authenticated planner pages.
- Users choose a task in plain language instead of needing to know which module owns it.
- **Show More Tools** reveals the full advanced navigation when needed.
- Contextual help strips explain the purpose of dense tools such as Event Workspace, Floor Plan Maker, Guests, Communications, Design Board and Financials.

## Dashboard task-first home
Prominent actions now include:
- Create an event
- Make a floor plan
- Build a design board
- Manage guests
- Message someone
- Handle money

## Floor Plan Maker
The floor plan tool is promoted to a first-class planning feature:
- Primary dashboard top-bar shortcut
- Primary dashboard task card
- Dedicated Plan & Design navigation group
- Global quick-action launcher
- Primary event-workspace shortcut
- Plain-language title: Floor Plan Maker
- Start Here panel
- Large one-tap buttons for Round Table, Long Table, Chair, Stage and Venue Plan upload
- Four-step guidance: Pick event → Add items → Drag → Save
- Existing professional controls remain available for advanced users

## Event Workspace
- Adds a visible Floor Plan Maker primary shortcut.
- Adds a four-step planning guide for Checklist, Design, Floor Plan and Guests.

## Design principle
Advanced capability is preserved, but core actions no longer require users to understand the application's internal module structure.
