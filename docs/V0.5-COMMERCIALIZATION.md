# v0.5 Commercialization & Self-Service

This release turns the standalone white-label planner into a sellable product layer without changing the underlying two-license model.

## Customer-facing additions
- Public pricing page for Single Event and Annual Unlimited.
- Read-only public demo workspace.
- Registration requires acceptance of Terms, Privacy Notice and EULA.
- Guided onboarding checklist for branding, email, payments and first event.
- Plan & Billing page with current expiration, license history, renewal, Annual upgrade and account export.
- Annual renewal extends from the later of the current expiration date or purchase date, preserving unused paid time.
- Single Event licenses are now bound to the specific event they authorize. A customer may later buy a new Single Event license on the same account without deleting historical events.

## Seller-facing additions
- Platform Owner Console now includes marketplace order fulfillment.
- Enter buyer name/email, source, marketplace order ID, plan and amount.
- Fulfillment generates a unique license code and activation URL.
- Direct Stripe purchases are recorded as platform orders automatically after payment verification.
- Redeemed marketplace codes link the resulting tenant back to the original order.

## Data ownership / legal
- Self-service JSON account export.
- Legal acceptance audit records include tenant, user, version, timestamp, IP and user agent.
- Starter Terms, Privacy Notice and EULA are included but must be reviewed by qualified counsel before public launch.

## License behavior
### Single Event
- Exactly one licensed event per Single Event entitlement.
- Access expires 90 days after the licensed event date.
- Historical events can remain in the account when a new Single Event license is purchased later.

### Annual Unlimited
- Unlimited events during the active license term.
- Renewal adds 12 months without discarding remaining paid time.

## Required deployment configuration
In addition to the existing environment variables:
- `PUBLIC_PRICE_SINGLE=99`
- `PUBLIC_PRICE_ANNUAL=499`
- `STRIPE_PRICE_SINGLE_EVENT`
- `STRIPE_PRICE_ANNUAL`
