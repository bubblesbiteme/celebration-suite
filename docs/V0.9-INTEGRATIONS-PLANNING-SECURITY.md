# Celebration Suite v0.9.0 — Integrations, Planning & Security

## Added
- Google Calendar OAuth connection with two-way operational sync: Celebration Suite event dates push to Google, Google events import as availability blocks.
- Manual calendar availability blocks.
- QuickBooks Online OAuth connection with encrypted tokens and company/invoice snapshot.
- TOTP two-factor authentication for planner/team accounts and optional client 2FA.
- Freeform event inspiration board using URL images or inventory images, with drag, resize, front/back layering and persistence.
- Inventory scan/lookup page showing item name, image, storage location, quantity and condition.
- Inventory reservation checkout/check-in server actions and return condition fields.

## Deployment
Run `supabase/migrations/0010_INTEGRATIONS_PLANNING_SECURITY.sql` after the prior migrations.

For Google Calendar, configure `GOOGLE_OAUTH_CLIENT_ID`, `GOOGLE_OAUTH_CLIENT_SECRET`, `GOOGLE_OAUTH_STATE_SECRET` (or `SESSION_SECRET`) and register `/.netlify/functions/google-calendar-callback` as an authorized redirect URI in Google Cloud.

For QuickBooks, configure `QUICKBOOKS_CLIENT_ID`, `QUICKBOOKS_CLIENT_SECRET`, and optionally `QUICKBOOKS_ENV=sandbox` during testing. Register `/.netlify/functions/quickbooks-callback` as the redirect URI in Intuit Developer.
