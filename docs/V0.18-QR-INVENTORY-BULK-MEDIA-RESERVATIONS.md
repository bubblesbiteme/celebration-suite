# Celebration Suite v0.18.0 — QR Inventory, Bulk Media & Reservation Sync

This release turns inventory into a single operational system across the master catalog, Design Studio, event reservations, packing, checkout and returns.

## QR inventory
- Persistent QR identity on every new inventory item.
- QR labels encode a direct Celebration Suite inventory lookup URL so native phone cameras can open the item.
- Printable 2×2 labels with wrapped item name and storage location/SKU.
- Bulk QR label printing from selected inventory items.
- Camera scanner plus manual barcode/SKU/QR lookup.
- Scan result shows primary photo, storage location, quantity, condition, SKU and reservation ledger.

## Bulk inventory upload
- CSV import from the Inventory screen.
- Up to 5,000 rows per batch.
- Matches existing items by SKU, barcode, or normalized item name and updates them instead of duplicating them.
- Import batch history records created/updated/error counts.
- Supported fields include name, category, sku, quantity, storage_location, condition, replacement_value, rental_price, rentable, barcode, image_url and notes.

## Inventory photos
- Dedicated `celebration-suite-inventory` Supabase Storage bucket.
- Up to 10 MB per image.
- Inventory image gallery table with primary-image designation.
- One-click photo upload on an inventory item.
- Bulk photo uploader automatically matches filenames to SKU, barcode, QR code or item name.
- Updating the primary inventory photo automatically updates every planner surface that consumes the inventory item's `image_url`, including Design Studio and event inventory.

## Design Studio approval → reservation
- Approved inventory-backed Design Studio items continue to create/update `design_quantity` reservations.
- Reservation records now retain the Design Studio item IDs responsible for the reservation.
- Manual and Design Studio quantities remain separate.
- Rejecting/removing an approved design releases only design-reserved quantity.
- Removing a manual reservation never deletes approved-design inventory holds.
- Event Inventory displays manual and approved-design quantities side-by-side.
