# Celebration Suite v0.6.1 — reliability, autosave and hotfix hardening

## Added
- Event Workspace local-first autosave with 2.5-second secure server debounce.
- Event Workspace recovery of newer unsaved local state after reload.
- Manual save retained, with explicit save-state messaging.
- Client message local + secure cloud draft persistence.
- Client cloud drafts are tenant-, client-, and event-scoped.
- Client Portal 45-second refresh while visible and online.
- Client Portal refresh on focus, tab return and reconnect.
- Client Portal dirty-edit protection so refresh does not wipe active typing.
- Event Day 45-second visible/online refresh plus focus/tab/reconnect refresh.
- Case-insensitive email identity lookup hardening across planner, platform admin, staff and client authentication paths.
- Migration `0007_RELIABILITY_DRAFTS_AND_SYNC.sql`.
- Permanent reliability/hotfix reference matrix in `docs/RELIABILITY-HOTFIX-REFERENCE.md`.

## Deployment order
1. Run migration `0007_RELIABILITY_DRAFTS_AND_SYNC.sql` in the Celebration Suite Supabase project.
2. Deploy the entire v0.6.1 package to the Celebration Suite Netlify project.
3. Use a fresh/incognito browser or hard refresh old open tabs.
4. Run the production smoke tests in the reliability reference document.

No Sage & Celebration production credentials or database resources are reused.
