# Celebration Suite v0.27.1 - Design Studio Inventory Button Hotfix

This hotfix corrects the Design Studio header's **Master Inventory** action.

Previously the button was hard-coded to `/inventory.html`, which opened the generic inventory module and broke the original Sage event-specific inspiration workflow.

The button now tracks the currently selected event and opens:

`/inventory-design-picker.html?booking_id=<event-id>`

The picker then allows the planner to choose an inventory item and quantity, add it to that event's inspiration board, and return to the same event workspace/design flow.

No database migration is required.
