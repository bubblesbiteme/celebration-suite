# v0.20 — Original Product Parity Bridge

This release uses the uploaded Sage & Celebration Phase 12 build as the behavioral reference instead of a feature-name checklist.

## Dense workflow parity added

### Event workspace / contract accounting
- Separate service/labor fee, client-funded non-reusable decor budget, and total contract.
- Event creation and Event Settings retain all three values.
- Financial Center reports service profit without treating the client decor allowance as planner revenue.
- Event workspace now links inventory calendar and staff scheduling directly.

### Staff scheduling / labor
- Default team hourly rate plus per-event override.
- Call time, shift end, planned hours, actual hours, lead designation and notes.
- Staff availability blocks and available overrides.
- Conflict warnings across overlapping shifts and unavailable periods with explicit override.
- Labor assignments create/update event expense records automatically.
- Event Day and Event Book consume the same staff schedule.

### Inventory operations
- Reservation calendar by event date.
- Planning reservation remains the source-of-truth hold.
- Separate operational movement history for packing, load-out and returns.
- Packed, loaded, good, damaged, repair and missing quantities.
- Expected return time and condition history.
- Manual and Design Board quantities remain separate.

### Questionnaires
- Reusable templates and CSV bulk template import.
- Public questionnaire links plus printable QR.
- Smart review flags and package-aware planning suggestions.
- Analyze & Create Plan converts questionnaire suggestions into Event Workspace checklist tasks.
- Analysis and plan-created state persist on the questionnaire.

### Floor plans
- Multiple named layouts per event.
- Layout types: Ceremony, Cocktail Hour, Reception and Custom.
- Duplicate, rename and delete controls.
- Guest/vendor assignment directly to objects.
- Setup notes and seat counts per object.
- Shared edit flag allows clients to update labels, seat counts and setup notes.
- Saved metadata tracks object count, seat capacity and assignment count.

### Final Event Book
Three print-ready packet modes:
1. Staff Production Book — full internal operations, inventory, labor and financial snapshot.
2. Vendor Packet — timeline, vendors, logistics, floor plans and operational inventory without private client/internal financial details.
3. Client Final Details — confirmed schedule, vendors, design, approved items, payment status and shared documents.

### Recovery / reliability
- Backup Center now supports dry-run restore validation.
- Table-by-table restore selection.
- Safe mode skips existing records by default.
- Overwrite must be selected explicitly.
- Exact confirmation phrase required: `RESTORE CELEBRATION DATA`.
- 10,000-row per-table / 40,000-row per-request safety caps.
- Sensitive auth/integration secrets are excluded from restoration.
- Restore run results are logged.

### QuickBooks inbound reconciliation
- Signed Intuit webhook endpoint: `/.netlify/functions/quickbooks-webhook`.
- Realm/company matching to the correct tenant integration.
- Incoming Customer / Invoice / Payment changes enter a review queue.
- Inspect fetches the current QuickBooks snapshot and differences.
- Supported Invoice and Customer mappings can be applied after review; other entity types remain review-only.
- Ignore is available without deleting audit history.

Required production variable for Intuit webhooks:
`QUICKBOOKS_WEBHOOK_VERIFIER_TOKEN`

### Support follow-up
- New support tickets can notify `SUPPORT_NOTIFICATION_EMAIL`.
- Waiting/resolved/closed status changes can send follow-up email.
