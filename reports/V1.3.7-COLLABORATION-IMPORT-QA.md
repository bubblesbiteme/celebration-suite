# Celebration Suite v1.3.7 — Collaboration & Import QA

## Reported issues covered

1. Floor Plan seating workflow moved from below the editor to a visible side workspace beside the canvas.
2. Planner and client Inspiration Board transforms persist to canonical inspiration item records; saves are serialized and transform write failures are no longer swallowed.
3. Planner and client uploaded documents open through authenticated signed-file endpoints.
4. Questionnaire CSV import strips BOM, supports quoted CSV, maps column aliases and boolean questions, preserves order, previews the import, and creates every parsed question.
5. Bulk inventory CSV preview uses a friendly table with human-readable headers instead of raw JSON.
6. Utility-page headers no longer show the Guided/Professional control where it has no effect; header actions are grouped consistently.
7. Master Inventory selection returns to the originating Inspiration Board/Event Workspace design tab with event context preserved.
