# Celebration Suite v1.2.1 — Functional Workspace Modes

This hotfix makes Guided Planning and Professional Workspace materially different in Event Workspace.

## Guided Planning
- Prioritizes Overview, Checklist, Timeline, Appointments, Guests, Financials, Documents, Inspiration, Floor Plan, Inventory, Approvals, Questionnaires, and Messages.
- Hides advanced professional event operations such as Vendors, Registration/Ticketing, Event Book, Reminders/Automations, Notes, Team, Change Orders, Activity, and Settings from the event workspace navigation.
- Simplifies Event at a Glance and Quick Actions.
- Displays an explicit Guided Planning status and explanation.

## Professional Workspace
- Restores the complete event workspace, including vendor, staff, registration, automation, change-order, audit/activity, and administrative tools.

## Behavior
- Switching mode rerenders immediately without reloading or changing event data.
- Preference persists locally between pages and sessions.
- The active event remains selected.
- Header Search and workspace-mode controls no longer collapse into wrapped text on desktop.

No database migration is required.
